# Filmorate

Filmorate – это Java-приложение, которое позволяет пользователям добавлять и оценивать фильмы, оставлять отзывы и получать рекомендации, а также ставить лайки фильмам и отзывам. Это приложение предлагает множество интересных функций, которые делают взаимодействие с фильмами более увлекательным и персонализированным.

## Функционал приложения

### Управление пользователями

- Получение друзей пользователя: Возвращает список друзей пользователя по его идентификатору.
- Добавление друга: Позволяет пользователю добавить другого пользователя в друзья.
- Удаление друга: Позволяет пользователю удалить друга из своего списка.
- Получение общих друзей: Возвращает список общих друзей между двумя пользователями.
- Получение всех пользователей: Возвращает список всех зарегистрированных пользователей.
- Получение пользователя по идентификатору: Возвращает информацию о пользователе по его идентификатору.
- Создание нового пользователя: Создает нового пользователя на основе предоставленных данных.
- Обновление данных пользователя: Обновляет информацию о пользователе.
- Удаление пользователя: Удаляет пользователя по его идентификатору.
- Получение ленты активности: Возвращает ленту активности для пользователя по его идентификатору.

### Рекомендации фильмов

- Получение рекомендаций по фильмам: Возвращает список рекомендованных фильмов для пользователя на основе его оценок и предпочтений.

### Управление отзывами

- Создание отзыва: Позволяет пользователю создать новый отзыв о фильме.
- Обновление отзыва: Позволяет пользователю обновить существующий отзыв.
- Удаление отзыва: Удаляет отзыв по его идентификатору.
- Получение отзыва по идентификатору: Возвращает информацию о конкретном отзыве.
- Получение отзывов по идентификатору фильма: Возвращает список отзывов для определенного фильма, ограниченный заданным количеством.
- Добавление лайка к отзыву: Позволяет пользователю поставить лайк на отзыв.
- Удаление лайка из отзыва: Позволяет пользователю убрать лайк из отзыва.
- Добавление дислайка к отзыву: Позволяет пользователю поставить дислайк на отзыв.
- Удаление дислайка из отзыва: Позволяет пользователю убрать дислайк из отзыва.

### Управление фильмами

- Получение фильма по идентификатору: Возвращает информацию о фильме по его идентификатору.
- Добавление нового фильма: Позволяет создавать новый фильм в базе данных.
- Обновление информации о фильме: Позволяет редактировать данные существующего фильма.
- Удаление фильма: Удаляет фильм по его идентификатору.
- Получение популярных фильмов: Возвращает список популярных фильмов с заданным количеством.
- Получение всех фильмов: Возвращает список всех доступных фильмов.
- Поиск фильмов по имени и критериям: Позволяет осуществлять поиск фильмов по заданному запросу и критериям.
- Получение популярных фильмов по жанрам и годам: Возвращает список популярных фильмов, соответствующих заданным жанру и году.
- Получение общих фильмов с другом: Возвращает список фильмов, общих для двух пользователей.

### Управление режиссерами

- Получение режиссера по идентификатору: Возвращает информацию о режиссере по его идентификатору.
- Получение всех режиссеров: Возвращает список всех режиссеров.
- Создание нового режиссера: Позволяет добавить нового режиссера в базу данных.
- Обновление информации о режиссере: Позволяет редактировать данные существующего режиссера.
- Удаление режиссера: Удаляет режиссера по его идентификатору.
